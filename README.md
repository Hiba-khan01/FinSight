## 📖 Overview

FinSight is a responsive personal finance dashboard built using **HTML, CSS, and JavaScript**. It enables users to monitor their financial health through interactive charts, spending insights, transaction management, and budgeting tools.

All data is stored locally in the browser, making the application fast, lightweight, and privacy-friendly.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Hiba-khan01/FinSight.git
```

Open the project

```bash
cd FinSight
```

Run the project

Simply open `index.html` in your browser.

Or use VS Code Live Server for the best experience.
